The Broken Camp
Role
Game Designer, Gameplay Programmer & Level Designer
Timeline
University Final Year Project (2026)
Engine
UE 5
Genre
Single-Player Military Third-Person Shooter
// Overview

This is my Final Year Project and the largest Unreal Engine project I have worked on so far. The goal was to develop a third-person shooter that brings together gameplay programming, level design, AI, mission systems, and environment production into a complete playable experience. The project is now complete, shaped by structured playtesting and multiple rounds of iteration on gameplay, AI behaviour, and level design. Final set dressing, lighting, and optimisation are complete, taking the project from greybox through to a fully realised playable environment

// Responsibilities

Designed the level from concept art to final playable environment. Created the initial blockout and refined gameplay flow. Built gameplay systems using Blueprints. Developed enemy AI and combat encounters. Refined enemy placement, combat pacing, and player progression. Built the environment using Fab Marketplace assets. Created in-game cinematics using Unreal Sequencer. Currently testing, debugging, and optimising the project for the final build.

// Challenges & Solutions

One of the biggest challenges was refining the enemy AI while new gameplay features were still being added. I spent a lot of time testing combat encounters, adjusting enemy placement, patrol routes, and behaviour to improve the overall flow of each mission. As the project grew, debugging Blueprint systems and fixing issues between interconnected mechanics became a regular part of development, helping me build a more stable and organised project.

// Lessons Learned

This project gave me a much better understanding of how gameplay systems, AI, level design, and player progression work together. It also improved my Blueprint workflow, problem-solving, and level iteration process. During development, I also learned the fundamentals of Unreal Engine Sequencer, which helped me present gameplay moments and support the overall pacing of the project.
