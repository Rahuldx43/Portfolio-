About me

I’m a game designer working in Unreal Engine, based in Stoke-on-Trent, UK, with hands-on experience in level design, environment creation and gameplay mechanics. I build immersive game worlds, implement interactive systems using Blueprints, and optimise environments for performance.

I’m completing an MSc in Computer Game Design at Staffordshire University, finishing in August 2026. I found my passion for game development while studying for my B.Tech in Computer Science with Big Data Analytics, then taught myself Unreal Engine through personal projects, freelance work and studio experience.
